# pluotos.ai

> Premium AI Automation Agency Platform

Intelligent automation workflows engineered for continuous velocity. Specializing in n8n workflow development, WhatsApp Meta Cloud API automations, and custom AI integrations.

## Features
- **Frontend-only React + Vite + TypeScript**: Fast, reactive modern web application.
- **n8n Workflow Pipelines**: Visual automation architectures connecting tools seamlessly.
- **WhatsApp Meta Cloud API**: 24/7 conversational triage and lead generation.
- **Lime Accent Aesthetic**: Custom `#BDF208` glowing vignette branding.
- **Interactive 3D Experience**: Zoom deck transitions powered by Three.js.

## Getting Started
```bash
npm install
npm run dev
```

## Build & Deployment
```bash
npm run build
```
